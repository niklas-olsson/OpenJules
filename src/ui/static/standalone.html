OpenJules standalone service

Task and cohort operations are unavailable.

This intermediate service exposes health and this static status page. Webhooks, private task data, guidance, palette actions, cohort controls and WebSocket streams are disabled until an authenticated host-policy adapter is implemented and qualified.

A webhook secret, bearer token or supplied policy does not enable these routes. This page does not collect credentials or display private data.

Existing work

Existing task and cohort data is retained. Stopping or upgrading this service does not establish that earlier work stopped or finished. Reconcile unresolved work through its existing trusted host controls.

Explicit local and managed operation

Direct host-owned CLI commands retain their standalone trust model. The separately configured managed service keeps its authenticated authority and capture contracts. Neither is an automatic fallback from this page.
